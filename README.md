# `buildecho/actions`

GitHub Actions for bringing Echo into your CI/CD pipelines. Each action runs as a step in your own workflows, on infrastructure you control.

## Actions

| Action | Description | Status |
|---|---|---|
| [`library-mirror`](library-mirror/README.md) | Mirror Echo libraries (npm and PyPI) into your own Azure Artifacts feed. | ✅ Ready |

More actions are on the way.
